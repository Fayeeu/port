# เพิ่มบทความ

สร้างไฟล์ `.md` ในโฟลเดอร์นี้ โดยใส่ frontmatter ไว้ด้านบน:

```md
---
title: "ชื่อบทความ"
date: 2026-10-14
excerpt: "คำโปรยสั้นๆ สำหรับหน้ารวมบทความ"
category: "หมวดหมู่"
readTime: 3
---

เนื้อหา Markdown เริ่มตรงนี้
```

ชื่อไฟล์จะกลายเป็น slug เช่น `my-note.md` เปิดอ่านได้ที่ `/blog/my-note` รองรับหัวข้อ ย่อหน้า ตัวหนา ตัวเอียง ลิงก์ รายการ อ้างอิง และ fenced code block
